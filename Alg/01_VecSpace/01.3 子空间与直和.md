# 1.C 子空间与直和（通俗完整版）

先说两个常见疑问：
1. 线性空间 = 向量空间（同一个概念，两种叫法）。
2. R^3 就是三维欧式空间，也就是常见的 xyz 坐标空间。

## 1) 子空间判定
在大空间 V 里取一个子集 U。  
U 是子空间，当且仅当满足三条：
1. 包含零向量 0
2. U 里任意两个向量相加，结果还在 U
3. U 里任意向量乘任意标量，结果还在 U

人话：在 U 里面怎么“加”和“乘”都不会跑出去，而且一定经过原点。

## 2) R^3 里的直观例子
- 过原点的直线：是子空间
- 过原点的平面：是子空间
- 不过原点的直线或平面：不是子空间

## 3) 子空间的和
给两个子空间 U1、U2，定义：
U1 + U2 = { u1 + u2 | u1 属于 U1, u2 属于 U2 }

意思是：把“U1 里任意向量”和“U2 里任意向量”相加，所有结果放在一起。

## 4) 直和（重点）
先记一句话：  
直和 = 两个子空间只在零向量处相交。

### 4.1 普通的和（不一定是直和）
如果 U1 和 U2 有较多重叠，那么同一个向量可能有多种拆法：
alpha = u1 + u2

这时通常不是直和。

### 4.2 直和（干净的和）
当 U1 和 U2 只共享零向量时：
U1 交 U2 = {0}

这时每个向量的分解方式是唯一的。

### 4.3 最直白理解
1. 普通和：有重叠，分解可能不唯一
2. 直和：只在 0 相交，分解唯一

### 4.4 R^3 例子
- U1 = x 轴
- U2 = y 轴

两者公共部分只有 (0,0,0)。  
在它们张成的平面内，每个向量都能且只能拆成：
x 轴向量 + y 轴向量

所以这是直和。

## 5) 直和最简判断
1. 交集只有零向量
2. 向量分解只有一种方式

满足这两条，就可以判定为直和。

## 补充梳理（教材要点）

### 核心知识点与关键定义

- **子空间 (Subspace)**：V 的子集 U，在 V 的运算下自身构成向量空间。
- **子集的和**：U<sub>1</sub> + … + U<sub>m</sub> = {u<sub>1</sub> + … + u<sub>m</sub> : u<sub>j</sub> ∈ U<sub>j</sub>}。
- **直和 (Direct sum)**：和空间中每个元素可**唯一**分解为 u<sub>1</sub> + … + u<sub>m</sub>，记 U<sub>1</sub> ⊕ … ⊕ U<sub>m</sub>。

### 重点结论与公式要点

- **子空间判定**：0 ∈ U；加法封闭；标量乘法封闭。
- **子空间的和**仍是子空间，且是包含 U<sub>1</sub>, …, U<sub>m</sub> 的**最小**子空间。
- **直和判定**：0 的唯一分解为全零；两子空间时 U + W 为直和 ⟺ U ∩ W = {0}。

### 案例数据与易错细节

- **案例**：满足 f′(2) = b 的可微函数集，仅当 b = 0 时为子空间。
- **案例（非直和）**：**F**<sup>3</sup> 中 U<sub>1</sub> = {(x, y, 0)}，U<sub>2</sub> = {(0, 0, z)}，U<sub>3</sub> = {(0, y, y)} 可张成全空间但非直和——(0, 0, 0) = (0, 1, 0) + (0, 0, 1) + (0, −1, −1)。
- **易错**：子空间的**并**通常不是子空间；U ∩ W = {0} **不能**直接推广到三个以上子空间的直和判定。
