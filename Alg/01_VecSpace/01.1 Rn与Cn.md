# 1.A R^n 与 C^n

## 1) 直观对象

- R^n：n 维实向量空间，元素是 n 维实数组  
  x = (x1, x2, ..., xn), 每个 xi 属于 R
- C^n：n 维复向量空间，元素分量属于 C

在应用中可理解为：

- 因子暴露向量
- 收益向量
- 风险参数向量

## 2) 两个基本运算

1. 向量加法（分量对应相加）  
   (x1,...,xn) + (y1,...,yn) = (x1+y1,...,xn+yn)
2. 数乘（标量乘每个分量）  
   lambda*(x1,...,xn) = (lambda*x1,...,lambda*xn)

## 3) 八条基础规则（后面变成公理）

对任意向量 u,v,w 和标量 lambda,mu：

1. u+v = v+u
2. (u+v)+w = u+(v+w)
3. 存在 0，使 v+0 = v
4. 对每个 v 存在 -v，使 v+(-v)=0
5. lambda*(u+v) = lambda*u + lambda*v
6. (lambda+mu)*v = lambda*v + mu*v
7. lambda*(mu*v) = (lambda*mu)*v
8. 1*v = v

## 补充梳理（教材要点）

### 核心知识点与关键定义

- **复数 (Complex number)**：形式为 a + bi 的数，其中 a, b ∈ **R**，全体复数构成的集合记为 **C**。
- **F 的统称**：符号 **F** 统一表示实数集 **R** 或复数集 **C**，其中的元素统称为**标量 (scalar)**。
- **组 (List) 与长度 (Length)**：长度为 n 的组是由 n 个有顺序的元素构成的序列，表现形式为 (x<sub>1</sub>, …, x<sub>n</sub>)。其与集合的本质区别在于：组内的元素**有顺序**且**允许重复**。
- **F**<sup>n</sup> **空间**：由 **F** 中元素组成的长度为 n 的组的全体集合。
- **F**<sup>n</sup> **中的加法与标量乘法**：加法为对应坐标相加；标量乘法为标量与每个坐标分别相乘。

### 重点结论与公式要点

- **复数运算**：(a + bi) + (c + di) = (a + c) + (b + d)i；(a + bi)(c + di) = (ac − bd) + (ad + bc)i。
- **复数的代数性质**：交换性、结合性、加法/乘法单位元、加法逆元与乘法逆元。
- **F**<sup>n</sup> **的加法性质**：满足交换性 x + y = y + x。

### 案例数据与易错细节

- **案例**：(2 + 3i)(4 + 5i) = −7 + 22i。
- **案例**：**R**<sup>2</sup>、**R**<sup>3</sup> 中向量可视为始于原点的箭头，加法对应平行四边形法则。
- **易错**：组 (3, 5) ≠ (5, 3)，但 {3, 5} = {5, 3}；组 (4, 4) ≠ (4, 4, 4)，但 {4, 4} = {4}。
- **易错**：符号 0 可能是标量 0，也可能是零向量 (0, …, 0)，需看上下文。

### 逻辑脉络与关联推演

- 从 **R** 到 **C**，再抽象为标量域 **F**，借 **R**<sup>2</sup>、**R**<sup>3</sup> 几何直观推广到 **F**<sup>n</sup>，为后续「向量空间」公理化提供具体模型。

- 任意域（Fields）的严格定义（如特征为 p 的有限域）。
- 相空间、机器学习特征向量等 **R**<sup>n</sup> 应用实例。
