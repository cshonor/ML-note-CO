# §4.4 中心极限定理（CLT）

中心极限定理描述：**适当标准化后的「和」或「均值」**，在 n 很大时**依分布收敛**到**标准正态**（与弱大数定律的「依概率收敛到常数」不同）。本章**纯文本**写公式。

---

## 1. 林德伯格–列维（Lindeberg–Lévy）CLT（独立同分布情形）

### 适用条件
- X_1, X_2, …, X_n **独立同分布（i.i.d.）**；  
- 期望 E(X_i) = mu、方差 D(X_i) = sigma^2 **存在**，且 **sigma^2 > 0**。

### 定理结论
标准化部分和**依分布收敛**到标准正态：

[ sum_{i=1}^n X_i - n*mu ] / ( sigma * sqrt(n) )   ->d   N(0,1)   （n -> ∞）。

**等价写法**（样本均值）：令 X_bar = (1/n) sum X_i，则

( X_bar - mu ) / ( sigma / sqrt(n) )   ->d   N(0,1)。

### 白话
原始分布不必是正态；只要 i.i.d. 且方差有限为正，**n 足够大时，和（或均值）的分布形状**接近正态（在标准化意义下）。

---

## 2. 棣莫弗–拉普拉斯（De Moivre–Laplace）CLT

### 适用条件
Y_n ~ B(n, p)，即 n 次独立伯努利试验的成功次数，单次成功概率为 p。

### 定理结论

( Y_n - n*p ) / sqrt( n * p * (1-p) )   ->d   N(0,1)   （n -> ∞）。

即：**大 n 下二项分布可用正态分布近似**（在标准化或连续性修正下计算概率，以教材为准）。

### 常用经验判定
当 **n p >= 5** 且 **n (1-p) >= 5** 时，正态近似往往较可用（经验法则，非定理条件）。

### 与林德伯格–列维的关系
令 X_i 为第 i 次试验的 0-1 成功指示变量，则 X_i i.i.d.，E(X_i)=p，D(X_i)=p(1-p)，且 Y_n = sum X_i。对 sum X_i 套用上一节的 CLT 即得本定理，故 **棣莫弗–拉普拉斯是林德伯格–列维的特例**。

---

## 核心对比表

| 定理 | 分布要求 | 矩条件 | 核心用途 |
| :--- | :--- | :--- | :--- |
| **林德伯格–列维** | **i.i.d.**（任意共同分布） | E、D 存在且 **D>0** | 大样本下**和/均值**标准化后 **->d N(0,1)** |
| **棣莫弗–拉普拉斯** | **二项 B(n,p)** | p 非退化时方差 n p(1-p)；实用上常配合 **np、n(1-p)** 较大 | **二项**概率用**正态近似**计算 |

---

## 大数定律 vs 中心极限定理（一句话）

- **大数定律（弱）**：样本均值 **依概率** 贴近真期望（「**值**」稳定到常数）。  
- **中心极限定理**：标准化后的和/均值 **依分布** 贴近正态（「**形状**」稳定到正态曲线）。

二者回答的问题不同，常一起用：前者谈**一致性/收敛到参数**，后者谈**渐近分布/推断与检验**。

---

## 应用要点（做题套式）

1. 识别是否为 **i.i.d. 部分和** 或 **二项 Y_n**。  
2. 写出 **期望、方差**，套标准化分式 **(和 - 期望) / 标准差**，极限分布为 N(0,1)。  
3. 有限 n 下算 P(a < Y_n <= b) 时，常把 Y_n 近似为正态并视教材决定是否做 **0.5 连续性修正**。
