# §4.3 大数定律（弱大数定律）

以下三条都是**样本量 n 趋于无穷**时，关于**样本均值或频率**的**依概率收敛**结论；公式一律**纯文本**。与「依概率收敛」的等价写法：对任意 epsilon>0，

lim_{n->∞} P(|Z_n - c| < epsilon) = 1

与

lim_{n->∞} P(|Z_n - c| >= epsilon) = 0

等价（Z_n 为随机序列，c 为常数）。

---

## 1. 伯努利大数定律（Bernoulli）

### 条件
进行 n 次**独立重复**伯努利试验；事件 A 在每次试验中发生的概率为 p；记 n_A 为 n 次中 A 发生的次数。

### 结论
频率 f_n = n_A / n **依概率收敛**到 p，记作

n_A / n ->P p   （n -> ∞）。

等价表述：对任意 epsilon > 0，

lim_{n->∞} P( |n_A/n - p| < epsilon ) = 1。

### 意义
**频率稳定性**：大样本下事件发生的频率会稳定在概率 p 附近；是用频率估计概率的理论依据之一。

---

## 2. 切比雪夫大数定律（Chebyshev）

### 条件
设 X_1, X_2, … **两两不相关**；E(X_k) = mu_k，D(X_k) = sigma_k^2，且存在常数 C 使 **sigma_k^2 <= C** 对所有 k 成立（方差**一致有上界**）。

### 结论
样本均值与「期望的算术平均」之差依概率趋于 0：

(1/n) * sum_{k=1}^n X_k  -  (1/n) * sum_{k=1}^n mu_k   ->P   0   （n -> ∞）。

等价：对任意 epsilon > 0，

lim_{n->∞} P( |(1/n)sum X_k - (1/n)sum mu_k| < epsilon ) = 1。

### 特例
若 mu_k 恒等于同一常数 mu，则

(1/n) * sum_{k=1}^n X_k   ->P   mu。

### 注
**伯努利大数定律**可看作特例：令 X_k 为第 k 次试验中 A 是否发生的 0-1 指示变量，则 sum X_k = n_A，E(X_k)=p，D(X_k)=p(1-p) 有界，且独立蕴含不相关。

---

## 3. 辛钦大数定律（Khinchin）

### 条件
X_1, X_2, … **独立同分布（i.i.d.）**；存在期望 E(X_k) = mu（**不要求方差存在**）。

### 结论
样本均值依概率收敛到总体期望：

(1/n) * sum_{i=1}^n X_i   ->P   mu   （n -> ∞）。

等价：对任意 epsilon > 0，

lim_{n->∞} P( |(1/n)sum X_i - mu| < epsilon ) = 1。

### 特点
在常见弱大数定律中条件相对**弱**（只要求 i.i.d. + 一阶矩），**应用面最广**。

---

## 三大定律对比表

| 定律 | 独立性要求 | 同分布 | 矩条件 | 核心结论 |
| :--- | :--- | :--- | :--- | :--- |
| **伯努利** | 独立（重复试验） | 同 0-1 结构 | p(1-p) 有限 | **频率 n_A/n** ->P **p** |
| **切比雪夫** | **两两不相关** | **不要**求同分布 | **方差一致有上界** | **样本均值** 与 **(1/n)sum E(X_k)** 之差 ->P **0** |
| **辛钦** | **独立** | **同分布** | **期望存在**（可无方差） | **样本均值** ->P **mu** |

---

## 易错点速记

1. **「弱大数」**指的是**依概率收敛**到常数（或到 0 的偏差），不要与**强大数**（几乎处处收敛）混淆。  
2. **切比雪夫**：要**不相关 + 方差有公共上界**；不是 i.i.d. 也能用，但结论形式是「减去 (1/n)sum mu_k」。  
3. **辛钦**：**i.i.d. + 期望存在**即可，**不必**有方差；比切比雪夫条件在「分布」上更强（同分布），在「矩」上更弱（无方差要求）。  
4. 三条结论都是**大样本**渐近性质；有限 n 下只有概率不等式（如切比雪夫不等式）给出偏差上界，与 LLN 不同层面。
