# §4.1 随机变量序列的两种核心收敛性

本章把**依概率收敛**与**依分布收敛（弱收敛）**的定义、人话含义、强弱关系、和计量/时序里的用处写清楚；公式一律**纯文本**。

---

## 1. 依概率收敛（Convergence in Probability）

### 定义
对任意 epsilon > 0，若

lim_{n->∞} P(|X_n - X| >= epsilon) = 0，

则称随机变量序列 {X_n} **依概率收敛**到 X，常记作 X_n ->P X（或 P-lim X_n = X，记号以教材为准）。

### 人话
n 越来越大时，X_n 与 X **相差超过任意固定门槛 epsilon** 的概率，会趋于 0。  
直观：**大样本下 X_n 会“贴在”X 附近**，只有越来越小概率会“跑远”。

### 核心应用
- **大数定律（LLN）**：样本均值等常是**依概率收敛**到总体期望（切比雪夫、伯努利等表述略有不同，本质常与“概率上稳定到常数”相关）。  
- **计量**：**一致估计量**——n 趋于无穷时，估计量**依概率收敛**到真参数。

---

## 2. 依分布收敛（Convergence in Distribution，弱收敛）

### 定义
设 F_n(x) 为 X_n 的分布函数，F(x) 为 X 的分布函数。若对 F 的**每一个连续点** x，都有

lim_{n->∞} F_n(x) = F(x)，

则称 {X_n} **依分布收敛**到 X，常记作 X_n ->d X（或 X_n => X）。

### 人话
n 变大时，X_n 的分布函数曲线在 F 的连续点上**逐点逼近** F。  
它**不直接要求** X_n 与 X 作为函数/路径“数值接近”，只要求**分布长得像**。

### 核心应用
- **中心极限定理（CLT）**：适当标准化后的样本均值（或和）**依分布收敛**到正态分布。  
- **计量**：**渐近正态性**、大样本下 t/z 检验统计量的极限分布，都建立在**依分布收敛**上。

---

## 3. 区别与强弱关系（必背）

| 对比 | 依概率收敛 | 依分布收敛 |
| :--- | :--- | :--- |
| **主要看什么** | 随机变量（或向量）**本身**是否贴近目标 | **分布函数**是否在连续点上贴近 |
| **典型强度** | **更强** | **更弱** |
| **关系** | **依概率 => 依分布** | **依分布 推不出 依概率** |

### 反例思路（为什么“同分布”不够推出依概率到同一个 X）
设 X_n 与 X **相互独立**，且**同分布**：例如都满足 P(取值 1)=P(取值 -1)=1/2。则对一切 n，F_n(x)=F(x)，故 **X_n 依分布收敛到 X** 显然成立。  
但考察 |X_n - X|：当 X_n 与 X 取值不同时，|X_n-X|=2；相同时为 0。于是对 epsilon=1，有

P(|X_n - X| >= 1) = P(X_n 不等于 X) = 1/2，

极限**不为 0**，故 **X_n 不依概率收敛到 X**。  
（若把 epsilon 取在 (0,2) 之间，结论同类：概率卡在正数，不趋于 0。）

这说明：**分布相同只保证依分布“极限是自己那一套分布”，不保证随机元在同一样本空间里贴近。**

---

## 4. 学计量 / 时序时各管什么

### 依概率收敛：估计量“一致”
样本量增大时，估计量（如 OLS beta_hat）**依概率收敛**到真参数 beta，即**一致性**。这是估计量很基础的一条“及格线”。

### 依分布收敛：假设检验与置信区间
CLT 给出统计量**极限分布**；大样本下用正态或卡方近似做检验/区间，依赖的是**依分布收敛**到已知分布，而不需要路径上逐点贴近某个固定随机变量。

---

## 5. 补充：两种更强的收敛（以后会遇到）

1. **几乎处处收敛（a.s. 收敛）**  
   比依概率收敛更强：除一个概率为 0 的集合外，样本路径上 X_n 逐点收敛到 X。与**强大数定律**等联系紧密。

2. **均方收敛（L2 收敛）**  
   若 E[(X_n - X)^2] -> 0，则必**依概率收敛**到 X（切比雪夫不等式可连起来）。在时间序列、线性预测、均方误差分析里常见。

---

## 6. 一句对照记

- **依概率**：**“量”要贴上去**（大偏差概率消失）。  
- **依分布**：**“形”（分布）要像起来**（CDF 在连续点贴合）。
